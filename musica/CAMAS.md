# Camas para Suno

Los archivos ya están vinculados. El juego pide `.opus` primero (más liviano). Si el navegador no sabe Opus (Safari viejo), intenta el mismo nombre en `.mp3`.

Suno, modo Custom:

- **Lyrics:** `[Instrumental]` (sin verso, sin coro, sin palabras).
- **Style:** pegá el bloque inglés de cada ranura.
- **Duración:** 2 minutos alcanza; el juego las va a looppear.
- Evitá finales heroicos, drops, voz, trap, piano pop y melodías que se clavan a los tres segundos. La corte ya sufrió eso.

Los toques al deslizar, sellar y consultar siguen en Web Audio. Esto es solo atmósfera.

## Orden de generación

### 1. `court` — Corte (la que más suena)

Suena casi siempre: primavera, verano, otoño, sin omen.

**Style (pegar en Suno):**
```
Dark medieval court ambient, instrumental only, low cello and viola ostinato, quiet lute arpeggio far in the back, distant soft choir pads without words, very slow 62 bpm, dry palace acoustic, muted antique gold mood, no drums, no snare, no melody hook that repeats every bar, no modern production, seamless loopable underscore for a card game, intimate and tired royalty
```

### 2. `winter` — Invierno

Reemplaza a la corte cuando es invierno (estación 4).

**Style:**
```
Winter medieval hall ambient, instrumental, frozen strings held long, sparse harp notes like dripping ice, low woodwinds, almost no percussion, 56 bpm, pale and hollow, cold stone cathedral reverb, no Christmas bells, no cheerful major themes, no vocals, loopable quiet underscore
```

### 3. `plague` — Fiebre de Vidrio

Si hay peste activa. Pisa invierno.

**Style:**
```
Plague medieval underscore, instrumental, sickly glass-like high sine pads, weak heartbeat-like low drum very far away, detuned viola, dry breath textures, 58 bpm, uneasy not horror-jump-scare, no metal, no scream vocals, no EDM, hospital-monastery atmosphere, loopable
```

### 4. `war` — Tres Banderas / motín

Guerra activa o motín. Pisa peste.

**Style:**
```
Distant medieval war camp ambient, instrumental, low war drums very muted and slow, tense low brass swells, bowed strings, no marching snare solo, no heroic fanfare, no choir lyrics, 72 bpm, smoke and banners mood, loopable underscore not a battle theme
```

### 5. `void` — Observatorio Negro

Estrella negra o puerta. Pisa guerra.

**Style:**
```
Cosmic occult medieval ambient, instrumental, deep drone, inverted bells, thin high harmonics, almost no rhythm, 50 bpm, black-star observatory, cold and vast, no trailer braams, no vocals, no risers, loopable void pad
```

### 6. `plot` — Conspiración

Copa, protocolo o correo activos / nombre en la mesa. Pisa el vacío.

**Style:**
```
Court intrigue underscore, instrumental, pizzicato strings very quiet, muted harpsichord fragments, low pulse, 68 bpm, someone listening behind a door, no jazz, no vocals, no big climax, loopable tension bed
```

### 7. `death` — La corona cae (una vez, no loop)

Stinger corto para la escena de muerte. 20–40 s. No hace falta que loopee.

**Style:**
```
Short medieval death stinger, instrumental, falling cello line, dry breath, last candle, 20 to 40 seconds, no choir singing words, no explosion, no modern drums, solemn and administrative not operatic
```

### 8. `coronation` — Menú / fundar / coronación (opcional)

Pantalla de inicio y escena de coronación. Puede ser la misma pista.

**Style:**
```
Quiet coronation ambient, instrumental, soft organ far away, one slow horn, 60 bpm, ermine and dust, not triumphant Hollywood, no lyrics, loopable for a start menu
```

## Cómo nombrarlo

Cuando Suno termine, bajá MP3 y dejalo en esta carpeta. Escribime una lista así:

| Ranura | Archivo que pusiste |
|---|---|
| court | `?.mp3` |
| winter | `?.mp3` |
| plague | `?.mp3` |
| war | `?.mp3` |
| void | `?.mp3` |
| plot | `?.mp3` |
| death | `?.mp3` |
| coronation | `?.mp3` |

Con eso los engancho al mute ♪ y a las camas. Si alguna te sale demasiado marcada, regenerá pidiendo *more pad, less melody*.
